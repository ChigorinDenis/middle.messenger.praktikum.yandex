# 💬 Проект Чат

Учебный проект чат-приложения, созданный с использованием **TypeScript** и **самописного фронтенд-фреймворка**, вдохновлённого архитектурой React.  
Проект демонстрирует базовые принципы компонентного подхода, реактивного обновления DOM и роутинга без сторонних библиотек.

## 🧠 Основная идея

Цель проекта — показать, как можно реализовать **SPA (Single Page Application)** без React, Vue или Angular.  
Всё приложение построено на самописном мини-фреймворке, включающем:

- 🔧 Класс `Block` — для управления состоянием, жизненным циклом и ререндером компонентов  
- 🧩 Шаблонизатор Handlebars — для декларативного описания интерфейса  
- 🧭 Класс `Router` — для управления навигацией без перезагрузки страницы  
- 🗂 Система компонентов и событий, объединяющая шаблоны и логику

## ⚙️ Технологии

- **TypeScript**  
- **Handlebars**  
- **SCSS / CSS Modules**

---

## 📦 Установка и запуск

- `npm install` — установка зависимостей,
- `npm run dev` —  запуск в режиме разработки,
- `npm run start` — Для запуска локального сервера с собранной версией приложения используйте,
- `npm run build` — сборка для продакшена,
- `npm run lint` — запуск линтера кода,
- `npm run lint:styles` — запуск линтера стилей,
- `npm run test` — запуск тестов.
